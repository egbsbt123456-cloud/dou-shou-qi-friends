# Dou Shou Qi Friends · 斗兽棋

经典斗兽棋（丛林棋），浅色界面、动物 emoji 棋子，支持 **人机对战、好友联机、本地双人**。从桌游平台中独立整理，只包含斗兽棋与它需要的账号服务。

## 本地运行

需要 Node.js 24 和 pnpm 10.34.9。项目包含原生 SQLite 依赖，安装时允许其构建脚本运行。

```sh
pnpm install --frozen-lockfile
```

把 `.env.example` 复制为 `.env`，然后：

```sh
pnpm db:migrate
pnpm dev
```

打开 http://localhost:5179 。后端只监听本机 3009 端口。

- 人机：游客执红先行，电脑执蓝；电脑在 Web Worker 中搜索，支持悔棋和重新开局。
- 本地双人：同一屏幕红蓝轮流，悔棋退一步，不需要账号。
- 好友联机：双方各自注册/登录，房主建房并分享 10 位房间码，好友加入执蓝，两人到齐后开局；蓝方看到的棋盘自动翻转。测试两个账号时请使用不同浏览器或隐私窗口，普通标签页会共用登录 Cookie。

## 规则（standard-1.0）

- 9 行 × 7 列，红方先行。兽力：象 8、狮 7、虎 6、豹 5、狼 4、狗 3、猫 2、鼠 1，棋子右下角标出兽力。
- 每步横竖走一格；不能进入己方兽穴。兽力大于或等于对方即可吃；鼠能吃象，象不能吃鼠。
- 只有鼠能下河；河里与岸上的棋子不能互吃。
- 狮、虎可横竖跳过整段河，河中有任何棋子时不能跳。
- 落入对方陷阱的棋子，任何对方棋子都能吃（包括象吃陷阱里的鼠）。
- 进入对方兽穴、吃光对方棋子，或让对方无子可走，即获胜。

## 联机行为

服务器持有棋局，校验身份、轮次、坐标、规则和版本。客户端只提交走法；同一请求重试不会重复执行。棋局和着法存入 SQLite，刷新后可从“继续我的房间”恢复。客户端约每 1.2 秒同步一次，网络中断不立即判负。等待房间可取消；进行中的对局可认输。最多同时保留 3 个进行中的房间。

本版没有计时、匹配、观战、联机悔棋、长捉与重复局面裁决、排行榜或积分；电脑不承诺特定棋力。

## 检查与构建

```sh
pnpm typecheck
pnpm test
pnpm build
```

`pnpm test` 覆盖规则（下河、跳河与阻挡、鼠象、河岸、陷阱、三种胜负）、电脑对手、账号与房间权限、并发加入、非法走法、请求幂等、版本冲突、重启恢复，以及三种棋盘模式。

前端产物位于 `apps/web/dist`，后端产物位于 `apps/server/dist`。

## 只玩离线版

`portable/斗兽棋-直接打开.html` 是单文件版，不需要安装依赖，双击即可，默认人机对战。`portable/index.html` 可选择人机或本地双人。好友联机必须运行完整项目和服务器，不能只上传静态 HTML。

## 上线

见 [docs/deployment.md](docs/deployment.md)。生产环境须配置自己的 HTTPS 域名、WEB_ORIGIN 和持久数据库位置。仓库不包含真实域名配置、账号、数据库、Cookie、SSH 密码或生产日志；`.env.example` 仅是本地示例。

这是独立发行版，数据库从迁移 1 开始，**不要把其它平台的数据库直接放进来**。账号是基础用户名密码登录，没有找回密码、邮箱验证或管理后台。

## 源码结构

- `apps/web`：Vue 外壳页面、账号界面、`public/dou-shou-qi` 棋盘页面与浏览器模式测试。
- `apps/server`：Fastify 账号和好友房间 API、SQLite 持久化与测试。
- `packages/game-core`：服务器复用的纯规则与电脑对手。
- `packages/contracts`：房间与走法类型。
- `portable`：离线单文件入口。

规则源码在浏览器（`apps/web/public/dou-shou-qi/engine.js`）和服务器（`packages/game-core/src/doushouqi-engine.cjs`）各有一份，内容必须逐字相同，由测试检查。修改规则时请同时更新两份，再运行测试。
